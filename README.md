# Security Engineering Mentorship Labs

This repository documents an eight-week, hands-on security engineering lab series focused on building, testing, troubleshooting, and investigating security infrastructure in isolated environments.

Each project records the architecture, implementation, validation evidence, detection logic, troubleshooting process, and lessons learned. The goal is to demonstrate practical understanding, not simply reproduce installation instructions.

## Lab series

| Week | Project | Focus | Status |
| --- | --- | --- | --- |
| 1 | [Wazuh Multi-Agent SIEM and Detection Engineering Lab](./week-01-wazuh-multi-agent-lab/) | SIEM deployment, endpoint monitoring, FIM, custom detections | Complete |
| 2 | [Suricata and Wazuh Network Detection](./week-02-suricata-wazuh-integration/) | Network IDS integration, internal SYN-scan detection, SIEM validation | Complete |
| 3–8 | Additional security engineering labs | To be documented | Planned |

## Technologies and practices

- Wazuh
- Suricata
- Linux and Windows administration
- Docker
- SIEM and endpoint monitoring
- File Integrity Monitoring (FIM)
- Network intrusion detection
- Detection engineering
- Log and alert analysis
- Controlled validation with Nmap
- Technical troubleshooting and documentation

## Repository goals

- Deploy and validate security infrastructure.
- Integrate endpoint and network telemetry.
- Trace events through collection and analysis pipelines.
- Build and test custom detection rules.
- Investigate failures methodically.
- Document detection limits and tuning considerations.
- Publish sanitized, reproducible technical evidence.

## Safety and scope

All activities were performed in isolated lab environments for educational purposes. Credentials, authentication keys, private keys, and other secrets are intentionally excluded. Configuration examples are limited to the parts needed to explain the labs.
